# 렌더링 최적화

> 6가지 최적화 기법으로 GPU 파이프라인 효율 극대화

---

## 핵심 내용

| 기법 | 문제 | 해결 |
|------|------|------|
| **GS → VS Billboard** | Geometry Shader 파이프라인 병목 | VS에서 직접 쿼드 확장 |
| **Frustum Culling** | 화면 밖 시스템도 GPU 자원 소모 | BoundingSphere 테스트로 제거 |
| **LOD SpawnRate** | 먼 파티클도 동일 수량 시뮬레이션 | 거리별 SpawnRate 조절 (100%→10%) |
| **Priority Eviction** | 메모리 부족 시 모든 시스템 영향 | 우선순위 낮은 시스템부터 제거 |
| **Global CS Dispatch** | 시스템별 개별 디스패치 오버헤드 | 통합 디스패치로 호출 수 감소 |
| **Off-Screen Particles** | 대량 파티클의 Overdraw 비용 | 저해상도 렌더링 → Upsampling 합성 |

## WHY

- 각 기법이 **서로 다른 병목**을 해결: 파이프라인 / 불필요 연산 / 메모리 / 호출 오버헤드 / Overdraw

---

## 시각화 레이아웃 — 최적화 기법 그리드 (2×3)

```
┌──────────────────────┬──────────────────────┐
│ GS → VS Billboard   │ Frustum Culling      │
│ [GS 파이프라인 병목  │ [절두체 밖 시스템    │
│  제거, VS에서 직접   │  BoundingSphere      │
│  쿼드 확장]          │  테스트로 제거]      │
├──────────────────────┼──────────────────────┤
│ LOD SpawnRate        │ Priority Eviction    │
│ [가까움: 100%        │ [메모리 부족 시      │
│  중간: 50%           │  거리 40%            │
│  멀음: 10%]          │  가시성 30%          │
│                      │  나이 20%            │
│                      │  기본 10%]           │
├──────────────────────┼──────────────────────┤
│ Global CS Dispatch   │ Off-Screen Particles │
│ [개별 디스패치 통합  │ [저해상도 렌더링     │
│  → 호출 오버헤드     │  → Bilateral         │
│  감소]               │  Upsampling 합성]    │
└──────────────────────┴──────────────────────┘
```

- **2×3 그리드** 레이아웃, 각 칸에 아이콘 + 핵심 설명
- 각 칸의 상단에 **기법명 볼드**, 하단에 간결한 설명
- 칸마다 **아이콘/심볼** 배치:
  - GS→VS: 파이프라인 다이어그램 (GS에 X, VS에 ✓)
  - Frustum Culling: 절두체 도형 + 구
  - LOD: 거리별 3단계 크기 점
  - Priority: 가중합 수식 바
  - Global Dispatch: 통합된 화살표
  - Off-Screen: 작은 해상도 → 큰 해상도 화살표

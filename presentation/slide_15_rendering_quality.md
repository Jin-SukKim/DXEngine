# 렌더링 품질

> 시각적 완성도를 높이는 7가지 렌더링 기법

---

## 핵심 내용

| 기법 | 효과 |
|------|------|
| **Soft Particles** | 파티클-지형 교차부 하드 엣지 제거 → 부드러운 알파 페이드 |
| **Velocity Stretch** | 속도 방향으로 빌보드 늘림 → 속도감 표현 |
| **Curl Noise** | 비압축성 유체 기반 벡터 필드 → 유기적 움직임 |
| **2D Noise & UV Distortion** | 텍스처 좌표 왜곡 → 불, 연기 등 자연스러운 질감 |
| **Curve → LUT** | 커브 에디터 → Texture2DArray LUT → GPU O(1) 조회 |
| **Sprite Animation** | 수명 기반 프레임 전환 + 블렌딩 → 부드러운 애니메이션 |
| **Bloom** | 포스트 프로세싱 발광 → Additive 파티클 강조 |

## WHY

- 파티클의 **물리적 사실감**과 **시각적 매력**을 동시에 달성
- GPU에서 효율적으로 처리 가능한 기법들을 선별

---

## 시각화 레이아웃 — 적용 전/후 비교

### Soft Particles

```
Before: 파티클이 지형 뚫음 (하드 엣지) → After: 부드러운 알파 페이드
원리: 씬 깊이 - 파티클 깊이 → 차이만큼 알파 감소
```

- 좌측: 파티클이 지형을 **날카롭게 잘리는** 이미지
- 우측: **부드럽게 페이드**되는 이미지
- 하단 수식: `softFactor = saturate((sceneDepth - particleDepth) / softDistance)`

### Velocity Stretch

```
Before: 동그란 빌보드 → After: 속도 방향으로 늘어난 빌보드
원리: View Space에서 속도 방향 투영 → 쿼드 확장
```

- 좌측: 원형 빌보드
- 우측: 타원형으로 늘어난 빌보드 + 속도 벡터 화살표

### Curl Noise

```
Before: 직선 움직임 → After: 유기적 유체 느낌
원리: 비압축성 유체 시뮬레이션 기반 벡터 필드
```

- 좌측: 직선 궤적 파티클
- 우측: 곡선 궤적 파티클 (유체 느낌)

### Curve → LUT

```
커브 에디터 → CPU 샘플링 → Texture2DArray LUT → GPU O(1) 조회
크기/색상/알파를 수명 비율에 따라 자유롭게 제어
```

- 좌측: 커브 그래프 (Bezier/Noise)
- 중앙: 화살표 + "CPU 베이킹"
- 우측: 1D 텍스처 스트립 + "GPU O(1)" 라벨
- 하단: 파티클 수명에 따라 **크기/색상/알파가 변하는** 시퀀스 이미지

# Spawn 시스템 확장

> 6가지 Spawn 타입 + TextureSpawnBake로 다양한 파티클 발생 패턴 지원

---

## 핵심 내용

- **6가지 Spawn 타입**: Box, Sphere, Vertex, Surface, Texture, Custom
- **TextureSpawnBake**: 텍스처 색상 조건을 만족하는 메시 표면 위치를 GPU에서 **사전 베이킹**
- **UV Seam 감지**: 텍스처 래핑 아티팩트를 자동으로 방지
- **Burst & Rate**: 즉시 대량 발사(Burst) + 초당 지속 발사(SpawnRate) 이중 모드

## WHY

- 다양한 이펙트 표현 필요: 박스(폭발 파편), 구(에너지 구체), 메시 표면(캐릭터 발산), 텍스처(문양 발생)
- TextureSpawnBake: **런타임 부하 제로** — 사전 베이킹으로 스폰 위치 결정

---

## 시각화 레이아웃 1 — 6타입 그리드 (2×3)

```
┌────────────┬────────────┬────────────┐
│   Box      │  Sphere    │  Vertex    │
│ [박스 도형]│ [구 도형]  │ [점 도형]  │
│ 폭발 파편  │ 에너지 구체│ 메시 정점  │
├────────────┼────────────┼────────────┤
│  Surface   │  Texture   │  Custom    │
│ [삼각형]   │ [이미지]   │ [자유형]   │
│ 표면 보간  │ 색상 기반  │ 사용자 정의│
└────────────┴────────────┴────────────┘
```

- 각 칸에 **간단한 아이콘/도형**과 대표 용도 한 줄
- 배경색 그라데이션으로 기본형(상단) → 고급형(하단) 구분

## 시각화 레이아웃 2 — TextureSpawnBake 개념도

```
[TextureSpawnBake]
텍스처 이미지 ──▶ GPU 베이킹 ──▶ 스폰 위치 버퍼
(색상 조건)       (사전 처리)     (런타임 부하 제로)
```

- 좌측: 텍스처 이미지 (색상 영역 하이라이트)
- 중앙: GPU 아이콘 + "사전 베이킹" 라벨
- 우측: 포인트 클라우드 형태의 스폰 위치 버퍼 시각화
- 하단 주석: "참조 카운팅으로 동일 텍스처 결과 공유 (메모리 절약)"
